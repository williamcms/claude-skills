# Styling in Admin UI

Source: https://admin-ui.vercel.app/documentation/developing/styling

Admin UI styles are prop-based (built on Stitches). Components take a `csx` prop; native elements use the `csx` function to generate a `className`.

## csx

Transforms a StyleObject into a `className`. Use it on native HTML elements and on libraries that accept `className`. Execute `csx` calls outside component functions for better performance.

```typescript
import { csx } from '@vtex/admin-ui'

const navStyle = csx({
  bg: 'muted',
  'button + button': { marginLeft: 2 },
})

function Example() {
  return <nav className={navStyle} />
}
```

## cx

Combines two or more classNames generated by `csx` or native classes.

## dataAttr

Generates data-attribute selectors for styling component variants. Components that implement variants via data attributes require matching selectors when overriding their styles:

```typescript
// dataAttr('variant', 'primary') => "[data-variant='primary']"
// dataAttr({ size: 'large', compact: true }) => "[data-size='large'][data-compact=true]"

// ❌ Won't override the primary variant
<Button className={csx({ bg: 'black' })}>Primary</Button>

// ✅ Correct
<Button
  className={csx({
    [dataAttr('variant', 'primary')]: { bg: 'black' },
  })}
>
  Primary
</Button>
```

## Token aliases

Design tokens are consumed as `$`-prefixed values on style props. Common shorthand aliases:

| Alias | Function |
|-------|----------|
| `bg` | background shorthand |
| `fg` | color (foreground) shorthand |
| `colorTheme` | applies coordinated color/background |
| `marginX` / `marginY` | horizontal/vertical margins |
| `paddingX` / `paddingY` | horizontal/vertical padding |
| `size` | width and height shorthand |

See [design-tokens.md](design-tokens.md) for the full token tables.

## Nesting, pseudo-classes, animations

- Nested selectors are supported (`'child-element': { ... }` inside the StyleObject). Avoid styling children from parents in reusable code; see [code-styleguide.md](code-styleguide.md).
- All CSS pseudo-classes (`:hover`, `:active`, `:focus`) and pseudo-elements (`:before`, `:after`) are supported.
- CSS animations are supported through a `keyframes` function.

## Responsive design

Mobile-first: every style targets mobile by default; each alias applies from its breakpoint up.

| Alias | Min-width | Max-width |
|-------|-----------|-----------|
| `@tablet` | 48em (768px) | — |
| `@tabletOnly` | 48em (768px) | 64em (1024px) |
| `@desktop` | 64em (1024px) | — |
| `@desktopOnly` | 64em (1024px) | 75em (1200px) |
| `@widescreen` | 75em (1200px) | — |

```typescript
<div
  className={csx({
    padding: '$s',
    '@tablet': { padding: '$m' },
  })}
/>
```

Components whose props accept `ResponsiveProp<T>` take per-breakpoint values:

```typescript
type ResponsiveProp<T> = T | {
  mobile: T
  tablet?: T
  desktop?: T
  widescreen?: T
}
```

## Rules of thumb

- Tokens over hardcoded values, always.
- Shorthand aliases over longhand CSS properties.
- Responsive aliases over value arrays or custom media queries.
- `dataAttr` selectors when overriding variant-based component styles.
